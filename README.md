# spk-moora

## Description
spk-moora is a Decision Support System (DSS) web application implementing the MOORA (Multi-Objective Optimization on the basis of Ratio Analysis) method. It assists users in making complex multi-criteria decisions through a robust and interactive interface.

## Key Features
- **MOORA Algorithm:** Specifically designed for decision support analysis.
- **Data Visualization:** Built-in charts and graphs powered by Recharts.
- **Interactive UI:** Supports drag-and-drop sorting via `@dnd-kit` and leverages Radix UI/Shadcn for components.
- **Export Capabilities:** Easily export data to PDF (`jspdf`) and Excel (`xlsx`).
- **State Management:** Efficient client-side state handling with Zustand.

## Tech Stack
- Next.js 15
- React 19
- Tailwind CSS
- Zustand
- Recharts
- jspdf & xlsx
